# Riel Linux 1.0.0

Stable Linux x86-64 release with the bundled .NET runtime and native editor suite.

## Highlights

- Refreshed English launcher with visible route and train information, clearer Play and
  Tools buttons, and seven selectable accent colors for light and dark themes.
- Saved-game selection prioritizes the selected snapshot and waits for its metadata.
  Timetable saves enter the existing resume flow, and content imports honor cancellation.
- Corrected texture sampler indexing, deferred night textures, instanced scenery root
  transforms and roof queries across tile boundaries. Referenced cyclic model hierarchies
  are rejected before graphics allocation while legacy truncated hierarchies retain their
  fallback behavior.
- Corrected text-field and modal-window input handling, plus location-label refresh when
  the selected mode or loaded scenery changes.
- Corrected tunnel traversal at section boundaries, repeated circuits and zero-length
  sections, per-crossing train eligibility, and split-platform direction calculations.
- Includes the nearby-train streaming fixes, camera snapshots, three-dimensional MSTS track
  placement and native Route Editor, Consist Editor, Shape Viewer and ACE Converter suite
  from previous releases.

Graphics defaults, LOD/culling policy, resource-lifetime rules, physics formulas and
simulation update frequencies are preserved.

## Validation

Publication is gated by 1,059 managed regression tests, shader validation/rebuild,
self-contained application publishing, native editor tests and UI/OpenGL smoke checks,
and portable-package checks without an installed .NET runtime. Launcher validation
also renders 119 interface previews.

## Downloads

Extract the complete `riel-linux-x64.zip` archive and run `./riel gui` from its directory.
The ZIP includes the .NET and editor runtimes; the .NET SDK is not required to play.
The release also includes the ZIP's SHA-256 checksum and matching editor source archive.
Routes and rolling stock are installed separately and retain their authors' licenses.

## Compatibility and known limitations

- Linux x86-64 requires an OpenGL 3.3 driver and the desktop libraries documented in
  [INSTALL.md](https://github.com/agustinluzardo/Riel-Linux/blob/v1.0.0/docs/linux/INSTALL.md).
  Vulkan through Mesa Zink remains experimental.
- Older saves, especially those predating the public assembly rename, are not fully
  verified. Third-party add-ons built against `FreeTrainSimulator.*` require rebuilding
  against `Riel.*`.
- Linux multiplayer remains unvalidated. A complete timetable restore-to-viewer gameplay
  session is not covered by the headless saved-game tests.
- Existing route-content differences remain, including the FCGR signal between Quilmes
  and Ezpeleta that can appear green while the route treats it as red.
- Confirmation of previously reported visual problems on affected custom routes and GPUs
  remains pending. Custom-route FPS improvements have not been measured.
